# Next.js Product Listing App

## Tech Stack
- Next.js
- React
- TypeScript
- Tailwind CSS

## Features
- Product listing page
- Product details page
- Search functionality
- Responsive UI
- Loading states

## Installation

git clone https://github.com/ShubhamBagal98/nextjs-product-listing.git
cd nextjs-product-listing
npm install
npm install lodash
npm install react react-dom
npm install --save-dev @types/react @types/react-dom
npm run dev
